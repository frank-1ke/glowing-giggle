SHOPEASE E-COMMERCE WEBSITE

FILES
- index.html: website page
- style.css: design and responsive layout
- script.js: product search, category filter, shopping cart, demo checkout

HOW TO USE ON A COMPUTER
1. Extract this ZIP file.
2. Keep all three code files in the same folder.
3. Open index.html in a browser.

HOW TO USE ON AN ANDROID PHONE
1. Download this ZIP file to your phone.
2. Open Files / My Files and find the ZIP in Downloads.
3. Tap Extract or Unzip.
4. Open the extracted ecommerce-website folder.
5. Open index.html with a browser or an HTML editor that can preview websites.

NOTE
This is a front-end demo. Product images need an internet connection. Checkout does not process payments or save orders to a server.
